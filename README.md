# В данном репозитории приведено решение задачи МатФизики методом Конечных элементов

Требуется найти $u \in H(\Omega) \. \Omega = [0;1] \times [0;1],$ удволетворяющее

$$
-(\nabla, \kappa \nabla u) + q u = f
$$

c краевыми условиями Дирихле и Неймана. Конкретные значения коэффициентов и вид краевых условий можно уточнить в материалах репозитория.
